# Development plan

1. Phase 1 (current): Electron foundation, tray, shortcut, deterministic typed commands, tests, and docs.
2. Phase 2: push-to-talk capture, offline transcription, Windows speech output, and cancellation.
3. Phase 3: SQLite conversation/memory store and optional Ollama adapter.
4. Phase 4: independently switchable, officially supported provider adapters and browser-assisted fallback.
5. Phase 5: payment approval and budget enforcement before any paid provider call.
6. Phases 6–9: files, research, programming workflows, email/calendar, packaging, and first-run setup.
